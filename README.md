# CS2 · инвентарь мечты

Инвентарь скинов CS2 с ценами Steam и процентами достижения цели.
Две вкладки — **Сейчас** и **Мечта**, три валюты (**$ / ₽ / ₸**), карточки
блоками и нормальная работа с телефона.

Страница полностью статическая: ни бэкенда, ни запросов к Steam из браузера.
Цены лежат в `data/catalog.json`, который пересобирается **на GitHub Actions**
раз в сутки — одним запросом к агрегатору цен, а не 19 тысячами запросов по
скинам.

---

## Запуск на компьютере

```
start.bat            (или: python serve.py)
```

Откроется `http://localhost:8787`. В консоли будет и адрес для телефона —
`http://<ip-компьютера>:8787`, если телефон в той же wi-fi.

`serve.py` — это просто раздача файлов, никакой логики в нём нет. Он нужен,
потому что браузер не разрешает читать json с `file://`.

## Что умеет

- **Поиск** по 13 900+ предметам: по-английски и по-русски, с транслитом
  («ак редлайн» → `AK-47 | Redline`, «авп азимов» → `AWP | Asiimov`).
  Фильтры прямо в запросе: `ft`, `stattrak`, `souvenir`, `кейс`, `нож`.
  Плюс кнопки категорий — винтовки, пистолеты, ножи, перчатки, кейсы и т.д.
- **Добавление**: плюс → поиск → скин → качество (FN/MW/FT/WW/BS в цветных
  овальчиках, как на ТП) → овальчики StatTrak™/Souvenir (взаимоисключающие,
  сувенирного StatTrak не бывает) → «Добавить».
- **Карточка предмета**: цены на все износы и все качества, кнопки
  «Изменить качество», «Открыть на ТП», «Удалить».
- **Мечта — это и есть цель.** Проценты считаются от суммы мечты:
  - «Сейчас»: одна полоса — стоимость инвентаря к стоимости всей мечты;
  - «Мечта»: зелёная — к предметам **1-го** порядка, жёлтая — к **1 + 2**
    (поэтому она всегда меньше), плюс фильтр по порядку.
- Валюта переключается одной кнопкой в шапке: **$ / ₽ / ₸**, курсы задаются
  в настройках.
- Данные хранятся в браузере (`localStorage`), есть экспорт/импорт JSON —
  так можно перенести инвентарь между компьютером и телефоном.

## Где берутся цены

| источник | что даёт |
|---|---|
| `data/catalog.json` | имена, картинки, редкость, цены по всем износам и качествам |
| `tools/build.py --sqlite` | собрать базу из `../cs2-prices/cs2_prices.db` (локально, без сети) |
| `tools/build.py --feed` | собрать из публичного агрегатора цен (одним запросом) |

Формат базы — компактный, чтобы телефон не давился:

```json
"AK-47 | Redline": {
  "t": "Covert Rifle", "c": "eb4b4b", "i": "<hash картинки>",
  "w": true,
  "p": {"n": [168.68, 41.2, 25.48, 26.42, 26.42],
        "s": [null, null, 79.31, 62.22, 43.07],
        "v": [null, null, 144.45, null, null]}
}
```

`n` — обычные, `s` — StatTrak™, `v` — Souvenir; пять чисел = FN, MW, FT, WW, BS;
`null` = нет лотов. Цены в долларах, пересчёт в ₽/₸ — в браузере.

## GitHub

```
git init
git add .
git commit -m "инвентарь мечты"
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Токен и логин в репозиторий не попадают (`.gitignore`), лучше вообще
авторизоваться один раз: `gh auth login`.

Дальше:

1. **Actions** → workflow `prices` работает сам (03:17 UTC) или по кнопке
   *Run workflow*. Он скачивает фид, пересобирает `data/catalog.json`,
   коммитит. Если фид сломался — коммита не будет, старая база останется.
2. **Settings → Pages → Deploy from a branch → main / (root)** — страница
   откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

> Приватный репозиторий + Pages — это платная функция GitHub (Pro/Team).
> Если план бесплатный: либо репозиторий публичный (код и база — не секрет),
> либо Cloudflare Pages / Vercel с тем же репозиторием (там приватные бесплатно).

### Почему не «сервер на GitHub»

GitHub не запускает долгоживущие процессы: Actions — это разовые задания по
расписанию, страница — статика. Поэтому схема «задание обновляет JSON, страница
его читает» — единственная рабочая без своего VPS. Зато телефон ничего не
считает и не ждёт: база уже готова.

Прямой скрапинг Steam из Actions **не** используется: датацентровые IP Steam
режет 429-ми (проверено и в проекте `cs2-prices`), плюс нужен залогиненный
аккаунт и Guard-коды.
