# CS2 · инвентарь мечты

Инвентарь скинов CS2 с ценами Steam и процентами достижения цели.
Две вкладки — **Сейчас** и **Мечта**, три валюты (**$ / ₽ / ₸**), карточки
блоками и нормальная работа с телефона.

Страница полностью статическая: ни бэкенда, ни базы данных. Имена, картинки и
снимок цен лежат в `data/catalog.json`, живые цены — в `data/live.json`.
Свежие цены собирает `collect.html`: одна кнопка, вставил исходник страницы
Steam — в базе обновились сразу все износы и качества этого скина. Приложение
читает готовый файл, поэтому на телефоне цены свежие без запросов к Steam.
Запасной путь — прямой запрос через публичный CORS-прокси `r.jina.ai`.

---

## Запуск на компьютере

```
start.bat            (или: python serve.py)
```

Откроется `http://localhost:8787`. В консоли будет и адрес для телефона —
`http://<ip-компьютера>:8787`, если телефон в той же wi-fi.

`serve.py` — это просто раздача файлов, никакой логики в нём нет. Он нужен,
потому что браузер не разрешает читать json с `file://`.

## Что умеет

- **Поиск** по 13 900+ предметам: по-английски и по-русски, с транслитом
  («ак редлайн» → `AK-47 | Redline`, «авп азимов» → `AWP | Asiimov`).
  Фильтры прямо в запросе: `ft`, `stattrak`, `souvenir`, `кейс`, `нож`.
  Плюс кнопки категорий — винтовки, пистолеты, ножи, перчатки, кейсы и т.д.
- **Добавление**: плюс → поиск → скин → качество (FN/MW/FT/WW/BS в цветных
  овальчиках, как на ТП) → овальчики StatTrak™/Souvenir (взаимоисключающие,
  сувенирного StatTrak не бывает) → «Добавить».
- **Карточка предмета**: цены на все износы и все качества, кнопки
  «⟳ Обновить цену» (живая цена с ТП), «Изменить качество», «Открыть на ТП»,
  «Удалить».
- **Мечта — это и есть цель.** Проценты считаются от суммы мечты:
  - «Сейчас»: одна полоса — стоимость инвентаря к стоимости всей мечты;
  - «Мечта»: зелёная — к предметам **1-го** порядка, жёлтая — к **1 + 2**
    (поэтому она всегда меньше), плюс фильтр по порядку.
- Валюта переключается одной кнопкой в шапке: **$ / ₽ / ₸**, курсы задаются
  в настройках.
- Данные хранятся в браузере (`localStorage`), есть экспорт/импорт JSON —
  так можно перенести инвентарь между компьютером и телефоном.

## Где берутся цены

| источник | что даёт |
|---|---|
| `data/catalog.json` | имена, картинки, редкость, снимок цен по всем износам и качествам |
| `tools/build.py --sqlite` | собрать базу из `../cs2-prices/cs2_prices.db` (локально, без сети) |
| сборщик (`worker/`) | **живые** цены Steam по твоим предметам, по кнопке «⟳ цены» |

### Живые цены

Есть два пути, оба работают без сервера.

**1. База цен в репозитории (основной).** Страница `collect.html` — одна большая
кнопка. Открываешь скин на ТП Steam, `Ctrl+U` → `Ctrl+A` → `Ctrl+C`, вставляешь
исходник в `collect.html`, жмёшь кнопку. Скрипт вытаскивает массив `buckets`
(там сразу **все износы и качества** этого скина со ценами), пересчитывает в
доллары и записывает `data/live.json` в репозиторий. Приложение читает этот
файл при запуске: на телефоне цены уже свежие, без единого запроса к Steam.

- валюту страницы определяет сам (`€`, `₽`, `₸`…) и пересчитывает в доллары;
  курс берётся биржевой, при желании задаётся вручную;
- без токена GitHub кнопка просто скачивает `live.json` — файл можно положить
  в `data/` руками;
- одна вставка = один скин целиком; можно вставлять несколько страниц подряд.

**2. Прямой запрос через прокси (запасной).** Браузер не может сам сходить на
Steam: тот не отдаёт `Access-Control-Allow-Origin`. Поэтому страница умеет
ходить через публичный прокси **`r.jina.ai`** (лимит ~20 запросов в минуту):

- кнопка **«⟳ цены»** обновляет все предметы открытой вкладки,
  **«⟳ Обновить цену»** в карточке — один скин,
  **«⟳ все износы»** — все варианты открытого скина;
- при открытии страницы цены обновляются автоматически, если им больше
  6 часов (можно выключить в настройках);
- живая цена помечена зелёной точкой и имеет приоритет над снимком каталога.

Почему не HTML со `strPrice` напрямую: страницу ТП нельзя прочитать из браузера
(CORS), а все публичные прокси на неё отвечают `451 Unavailable For Legal
Reasons` — Steam запрещает краулерам страницы площадки. Поэтому HTML берётся
руками, а всё остальное автоматизировано.

Если хочется быстрее и без лимита — есть необязательный сборщик:
`worker/worker.js` на бесплатном Cloudflare Workers (пошагово в
`worker/README.md`) или локальный `python tools/price_proxy.py 8788`.
Его адрес вставляется в **Настройки → «Сборщик цен»**, и он подменяет прокси:

```
POST <сборщик>/bulk  {"names": ["AK-47 | Redline (Field-Tested)", ...]}
-> {"items": {"AK-47 | Redline (Field-Tested)": {"price": 31.55}}}
```

Формат базы — компактный, чтобы телефон не давился:

```json
"AK-47 | Redline": {
  "t": "Covert Rifle", "c": "eb4b4b", "i": "<hash картинки>",
  "w": true,
  "p": {"n": [168.68, 41.2, 25.48, 26.42, 26.42],
        "s": [null, null, 79.31, 62.22, 43.07],
        "v": [null, null, 144.45, null, null]}
}
```

`n` — обычные, `s` — StatTrak™, `v` — Souvenir; пять чисел = FN, MW, FT, WW, BS;
`null` = нет лотов. Цены в долларах, пересчёт в ₽/₸ — в браузере.

## GitHub

```
git init
git add .
git commit -m "инвентарь мечты"
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Токен и логин в репозиторий не попадают (`.gitignore`), лучше вообще
авторизоваться один раз: `gh auth login`.

Дальше:

1. **Actions** → workflow `ci` проверяет, что каталог не побился (структура,
   количество предметов, корректность цен) и что файлы на месте. Запускается
   на push и по кнопке *Run workflow*.
2. **Settings → Pages → Deploy from a branch → main / (root)** — страница
   откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

> Приватный репозиторий + Pages — это платная функция GitHub (Pro/Team).
> Если план бесплатный: либо репозиторий публичный (код и база — не секрет),
> либо Cloudflare Pages / Vercel с тем же репозиторием (там приватные бесплатно).

### Почему не «сервер на GitHub»

GitHub не запускает долгоживущие процессы: Actions — это разовые задания по
расписанию, страница — статика. Ежедневная пересборка всей базы в Actions
умерла вместе с агрегатором `prices.csgotrader.app` (домен переехал на сайт
расширения), а сам Steam режет серверные IP и TLS Python 429-ми (проверено).
Поэтому база — снимок для поиска, а свежие цены считаются по требованию и
только для твоих предметов.

## Файлы

```
index.html                     страница
style.css                      оформление (mobile-first, тёмная тема)
app.js                         поиск, карточки, шторки, подсчёты, живые цены
collect.html                   сборщик: одна кнопка, HTML страницы -> data/live.json
data/catalog.json              база: имена, картинки, снимок цен
data/live.json                 живые цены (все износы), наполняется collect.html
tools/build.py                 сборка базы: --sqlite / --feed / --check
tools/price_proxy.py           локальный сборщик цен (тот же API, что worker)
worker/worker.js               сборщик для телефона (Cloudflare Workers)
worker/README.md               как выложить за 5 минут
serve.py / start.bat           локальная раздача + открыть браузер
.github/workflows/ci.yml       проверка базы и файлов
```
