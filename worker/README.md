# Сборщик цен для телефона (бесплатно, без сервера)

Одна маленькая функция на Cloudflare Workers. Зачем она нужна:

- браузер **не может** сам сходить на Steam — тот не отдаёт
  `Access-Control-Allow-Origin`, и запрос блокируется (проверено);
- публичные CORS-прокси и бесплатные агрегаторы умерли
  (`prices.csgotrader.app` снят, `corsproxy.io` требует ключ,
  `allorigins`/`codetabs` отдают 522);
- поэтому нужен ровно один посредник. Здесь он — 90 строк, бесплатный тариф
  Cloudflare: 100 000 запросов в день, карта не нужна.

Плюс главное: страница спрашивает цены **только тех скинов, что у тебя есть**
(10–50 штук), а не всю базу. Это 1 запрос и пара секунд вместо 19 000 запросов.

## Что отдаёт

```
GET  /price?name=AK-47%20%7C%20Redline%20(Field-Tested)&cur=1
POST /bulk   {"names": ["...", "..."], "cur": 1}
```

```json
{"ok": true, "count": 2, "ts": "2026-10-30T13:17:31Z",
 "items": {"AK-47 | Redline (Field-Tested)": {"price": 31.55, "median": 31.4, "volume": "79"}}}
```

Уже включено: CORS `*`, ограничение 4 запросов к Steam одновременно,
повтор при 429, кэш Cloudflare на 30 минут, лимит 40 имён за раз
(у бесплатного тарифа 50 подзапросов).

## Как выложить (5 минут, без консоли)

1. Зайти на <https://dash.cloudflare.com> → **Workers & Pages** → **Create**
   → **Worker**.
2. Назвать, например, `cs2-prices` → **Deploy**.
3. **Edit code** → стереть всё, что там есть, вставить целиком
   `worker/worker.js` → **Deploy**.
4. Скопировать адрес вида `https://cs2-prices.<твой-поддомен>.workers.dev`.
5. Открыть приложение → **⋯ / Настройки** → поле **«Сборщик цен»** → вставить
   адрес → «Проверить сборщик». Должно появиться «сборщик на связи».

После этого на телефоне работает кнопка **«⟳ цены»**: она обновляет
стоимость всех предметов открытой вкладки.

## Если хочется закрыть от чужих

В настройках Worker-а → **Settings** → **Variables** добавь `SHARED_KEY`
(любая строка). Тогда все запросы должны идти с `?key=...`. В приложении
тогда указывай адрес как `https://....workers.dev/?key=ТВОЙ_КЛЮЧ`
(остальные пути допишутся сами).

## Чего ожидать

- Цена = **низший лот на Steam Community Market** (`lowest_price`).
- Если лотов нет — `price: null`, приложение покажет снимок из каталога.
- Cloudflare ходит со своих IP; если Steam начнёт отвечать 429, Worker вернёт
  `"error": "429"` и страница просто останется на снимке каталога.
  Проверяется кнопкой «Проверить сборщик» и одной кнопкой «⟳ цены».

## Запасной вариант без Cloudflare

На компьютере: `python tools/price_proxy.py 8788` → в настройках указать
`http://127.0.0.1:8788`. Тот же API, ходит через `curl` (Steam режет
TLS-отпечаток Python, поэтому urllib только как запасной путь).
