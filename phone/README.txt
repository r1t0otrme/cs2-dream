CS2 · инвентарь мечты — версия для телефона
============================================

Один файл: cs2-dream.html. Внутри уже всё — база 13 925 предметов,
цены и кнопки. Ни сервера, ни папок, ни установки.

Как открыть
-----------
1. Перекинь cs2-dream.html на телефон: Telegram «Избранное», кабель,
   облако, почта — любым способом.
2. Открой файл и выбери браузер (Chrome / Safari / Яндекс).
3. Меню браузера → «Добавить на главный экран» — будет как приложение.

Что внутри
----------
- база предметов и цены на момент сборки — работают без интернета;
- «⟳ цены» и фоновый долив обновляют цены, если интернет есть;
- инвентарь, мечта и проценты хранятся в браузере телефона;
- экспорт/импорт (настройки ⋯) переносит список между телефоном и ПК.

Если хочется всегда свежую базу без файла — есть онлайн-версия:
https://r1t0otrme.github.io/cs2-dream/

Пересобрать файл после обновления базы:
    python tools/bundle.py
