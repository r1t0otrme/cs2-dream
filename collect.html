⟳ Сборщик цен ← в инвентарь
1. Открой скин на торговой площадке Steam. 2. Нажми Ctrl+U → Ctrl+A → Ctrl+C. 3. Вставь сюда (можно несколько страниц подряд) и нажми кнопку.
Цены берутся из массива buckets — сразу все износы и качества этого скина.
Куда писать · токен GitHub (один раз)
Токен хранится только в этом браузере и в репозиторий не попадает. Нужен fine-grained токен с правом Contents: Read and write на этот репозиторий.
Без токена жми «Скачать live.json» и закинь файл в data/ вручную — тоже работает.
